# Change log: 2026-10-03 / 003

- **Date:** 2026-10-03
- **Summary:** Added the central superadmin back office with independent
  authentication, organization status management, and an interactive account
  creation command.
- **Files added/changed/removed:** Added the superadmin model, migration,
  middleware, controllers, command, Blade views, feature tests, and user
  documentation. Updated `config/auth.php`, `routes/web.php`, and technical
  architecture documentation. Converted the existing organization migration
  to an anonymous migration so Laravel can resolve its filename safely, and
  forced PHPUnit's configured environment values to isolate tests from shell
  and container database settings.
- **Migrations:** Run central `php artisan migrate` to create `super_admins`.
- **New env vars:** None.
- **Commands to run:** `php artisan migrate`; `php artisan superadmin:create`.
- **Breaking changes:** None.
- **Manual steps:** Provision the first superadmin from the CLI before signing
  in at `/admin/login`.
