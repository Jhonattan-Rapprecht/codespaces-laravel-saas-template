# Change log: 2026-10-03 / 017

- **Date:** 2026-10-03
- **Summary:** Removed the `sed` dependency from the Keycloak entrypoint. The
  Keycloak image is minimal and most likely has no `sed`, which would make the
  container exit at start (`set -e`) before Keycloak runs, leaving port `8081`
  answering 502 and the `keycloak` hostname unresolvable. The realm template is
  now rendered with POSIX shell only; output is identical.
- **Files added/changed/removed:** Updated `.devcontainer/keycloak-entrypoint.sh`.
- **Migrations:** None.
- **New env vars:** None.
- **Commands to run:** None.
- **Breaking changes:** None.
- **Manual steps:** Rebuild the devcontainer (or recreate the `keycloak` service)
  so the entrypoint runs again, then follow `keycloak-development.md`. Not yet
  verified inside the Keycloak container: this workspace has no Docker access.
